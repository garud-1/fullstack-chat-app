<h1 align="center" id="title">Chatty</h1>

<p align="center"><img src="https://socialify.git.ci/garud-1/fullstack-chat-app/image?custom_language=React&amp;font=Bitter&amp;language=1&amp;name=1&amp;owner=1&amp;pattern=Circuit+Board&amp;stargazers=1&amp;theme=Dark" alt="project-image"></p>

<p id="description">Chatty is a scalable real-time web-based chat application built using the MERN stack (MongoDB Express.js React.js Node.js). It leverages Socket.io for bi-directional low-latency communication enabling instant messaging with minimal overhead. The application integrates JWT-based authentication and NodeMailer email verification to ensure secure and verified user sessions.</p>
